Kitty Defense is a small tower defense game built with Python and Pygame.

Protect the Cat Home from waves of naughty dogs by placing cats strategically along the road. Every cat automatically attacks nearby enemies, and your goal is to stop the dogs before they reach the Cat Home.

The game features three increasingly challenging levels, different dog breeds with unique movement speeds, and a simple treat economy that rewards careful tower placement.

Features

- Three progressively more difficult levels
- Three dog breeds with different movement speeds
- Placeable cat towers with attack range
- Automatic targeting and projectile combat
- Treat-based resource management
- Bonus treats after completing a level
- Game Over screen with the option to buy extra lives
- Custom graphics, sound effects, and game icon
- Animated starry menu background
- Polished user interface with multiple game screens

Technologies

- Python 3
- Pygame

Installation

Install Pygame:

pip install pygame

Run the game:

python main.py

Controls

- Left Mouse Button — Place a cat tower
- Cats attack automatically once an enemy is within range.
- Prevent the dogs from reaching the Cat Home.

Gameplay

Each cat costs 50 Treats to place.

Defeated dogs flee the battlefield and reward additional Treats, allowing you to build more defenses. Complete all three levels to successfully defend the Cat Home.

About This Project

Kitty Defense was developed as a personal Python project to practice game development with Pygame. It focuses on creating a complete and polished game while exploring topics such as object-oriented programming, game loops, collision detection, UI design, and game balancing.
